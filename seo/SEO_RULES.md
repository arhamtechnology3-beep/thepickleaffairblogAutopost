# SEO_RULES.md — Quick rules for The Pickle Affair

Masters:
- Blog: `/BLOG.md` (sections 0–83)
- Collections/Products: `/seo/SEO_AUTOPILOT.md`
- Prior collections paste pack: `/COLLECTIONS_SEO_PLAN.md`

## Never
- Fake search volumes
- Invent ingredients, health claims, recipes quantities, awards, reviews
- Keyword stuffing / doorway / city-only pages
- Copy competitor pages
- Publish 5 near-identical articles
- Optimize for “number of blogs published”

## Always
- One primary intent → one canonical URL (`BLOG_REGISTRY.md`)
- Verify product facts against Shopify before claims
- Quality gate + scorecard (§40, §77) before publish
- Prefer UPDATE/MERGE over NEW when intent overlaps
- Log changes in `/seo/logs/`

## Demand evidence order
1. Google Search Console  
2. Keyword Planner (if available)  
3. Connected SEO tools  
4. Autocomplete / SERP / competitor research  
5. Demand tier A/B/C with `volume unavailable`

## Publish cadence
- Default: 2–3 high-quality articles/week  
- Daily automation may draft, but publish only when gates pass  
- “5/day” = maximum, not a quota (`BLOG.md` §49)
